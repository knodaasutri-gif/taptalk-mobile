# TapTalk Mobile

TapTalk Mobile は、発話や意思疎通に支援が必要な方が、スマートフォン上の操作と音声入力でメッセージを伝えるための AAC（補助・代替コミュニケーション）Web アプリケーションです。外部ライブラリに依存せず、ブラウザ内で動作します。

## 主な機能

- **カテゴリ別定型文カードの読み上げ**：作業・指示、朝礼・挨拶、体調・移動、雑談・返答、お休み・遅刻の5カテゴリをタブで切り替え、2列グリッドのカードを選択して日本語音声で読み上げます。選択した文は画面上部の大きな表示エリアにも反映されます。
- **操作フィードバック**：カードや操作ボタンのタップ時に、視覚的な押下表現、チャイム音、対応端末でのバイブレーションを実行します。
- **Web Speech API による音声認識字幕**：マイクボタンで日本語音声認識を開始し、途中結果を含む認識テキストを表示エリアと自由入力欄へリアルタイムに反映します。認識が一時停止した場合は、利用中の状態を保って再開を試みます。
- **自由入力欄からの独立発話**：テキストを直接入力、または音声認識結果を修正してから、その文だけを読み上げられます。
- **お休み・遅刻連絡の自動作成**：日付（今日・明日・明後日のクイック選択を含む）、時刻、連絡種別（終日休み・遅刻・早退・午前休・午後休・通院）を選び、自然な連絡文を生成します。生成文は読み上げると同時にカードとして保存されます。
- **カスタムカード管理**：カテゴリ、絵文字、本文を指定したカードの追加・編集・削除に対応しています。
- **ローカル保存**：カード内容を `localStorage` に保存し、次回起動時に復元します。保存できないブラウザ環境でも初期カードで継続利用できます。
- **モバイル／PWA を意識した UI**：ビューポート設定、テーマカラー、スマートフォン向けレスポンシブレイアウト、タップ操作の最適化を備えています。なお、現時点では Web App Manifest と Service Worker は含まれていないため、インストール可能な PWA 化は未実装です。

## 技術構成

| 区分 | 内容 |
| --- | --- |
| 構造 | HTML5（`index.html`） |
| スタイル | CSS3（`style.css`） |
| ロジック | Vanilla JavaScript / ES6+（`script.js`） |
| 音声合成 | Web Speech Synthesis API（`speechSynthesis`、`ja-JP`） |
| 音声認識 | Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`、`ja-JP`） |
| 効果音 | Web Audio API |
| 触覚フィードバック | Vibration API（対応ブラウザのみ） |
| 永続化 | Browser `localStorage` |
| 外部依存 | なし |

## ファイル構成

```text
.
├── index.html        # 画面構造・入力UI
├── style.css         # モバイル向けレイアウト・操作フィードバック
├── script.js         # カード管理、音声処理、保存、表示制御

└── REQUIREMENTS.md   # 要件定義
```

## 使い方

1. `index.html` を対応ブラウザで開きます。
2. カテゴリを選び、定型文カードをタップして読み上げます。
3. マイクボタンで音声をテキスト化し、必要に応じて自由入力欄で修正して読み上げます。
4. カード追加・編集モードから、自分用のカードを管理します。
5. 「📅 お休み・遅刻」カテゴリでは、日付・時刻・種別を選択して連絡文を作成します。

## 動作上の注意

- 音声認識の利用には、ブラウザのマイク権限が必要です。対応していないブラウザでは音声入力ボタンが無効になります。
- 音声合成・音声認識・バイブレーションの対応状況は、端末やブラウザによって異なります。
- カスタムカードは同一ブラウザ内の `localStorage` に保存されます。ブラウザのデータ消去や別端末への移行では引き継がれません。
